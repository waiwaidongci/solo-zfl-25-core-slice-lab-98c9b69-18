# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 切片标签签发与扫码核销

访问`http://localhost:3025/labels`(旧首页有入口链接,原有功能保留)。

- **批量签发**:选模板版本和工序,按切片一次生成唯一有序标签;同一幂等键重复提交只返回原批次;超过 50 片或序号冲突整批失败、不产生部分写入。
- **扫码核销**:校验 HMAC 签名防篡改,只核销匹配切片且工序为当前工序的标签;跨片、跳步、篡改、重复扫码均失败且状态不变;过期标签自动作废。
- **作废与重印**:支持损坏/过期手动作废;重印生成新码,旧码立即作废。
- **模板升版**:升版只影响新标签,旧批次与旧标签保留可查。
- 页面展示签发批次、标签台账(有效/已核销/已作废及原因)和扫码记录;数据持久化在 `data/core-slices.json`,重启不丢。

实测脚本:`node test-labels.mjs`(需服务已启动)。
